## 🔐 Cyber

**Compromission de 173 tenants Microsoft 365 via ConnectWise**
Des hackers ont utilisé des credentials ConnectWise compromis pour accéder à 173 tenants M365 dans une attaque de type supply-chain.
*Impact : Risque direct sur les environnements cloud pharma utilisant ConnectWise comme outil de support/MSP ; auditer immédiatement les accès tiers aux tenants M365 et vérifier les logs de connexion.*

**Package npm malveillant 'imgdecode' avec shellcode caché**
Un package npm nommé `imgdecode` dissimule un loader de shellcode dans un addon natif Windows, ciblant les pipelines de développement.
*Impact : Menace directe sur les équipes DevOps/MLOps pharma utilisant npm ; renforcer le contrôle des dépendances open source (SCA) et appliquer une politique de registre privé.*
🔗 https://thehackernews.com/2026/10/malfex-npm-package-imgdecode-hides.html

**Drupal : correctifs critiques RCE, exploitation imminente**
Drupal a publié des patches pour des failles RCE critiques en avertissant que des exploits pourraient apparaître rapidement.
*Impact : Les portails patients, sites réglementaires ou intranets sous Drupal doivent être mis à jour en urgence ; vérifier l'exposition publique des instances.*
🔗 https://www.bleepingcomputer.com/news/security/drupal-patches-critical-rce-flaws-warns-exploits-may-emerge-soon/

**Cyberattaques étendues aux systèmes physiques de bâtiments**
Les cybercriminels ciblent désormais les systèmes BMS/BAS (gestion de bâtiment) au-delà du vol de données.
