## 🔴 Cybersécurité

**1. Java4Shell (CVE-2026-114938) — RCE pré-authentifiée sur Java 17+**
Une faille critique permet l'exécution de code à distance sans authentification sur Jira, Jenkins et Keycloak tournant sur Java 17+ avec extensions AVX-512 VBMI. La CISA exige un patch immédiat — tout environnement GxP utilisant ces outils (CI/CD, IAM, gestion de tickets) est directement exposé.
🔗 https://thehackernews.com/2026/11/java4shell-cve-2026-114938-enables-pre.html

**2. Clés cloud volées dans des images Docker Hub en quelques secondes**
Des secrets (clés API, credentials cloud) exposés dans des images Docker Hub sont détectés et exploités quasi instantanément par des bots automatisés. Risque direct pour les pipelines MLOps et les environnements de déploiement contenerisés en pharma — audit des images Docker en production requis.
🔗 https://www.bleepingcomputer.com/news/security/cloud-keys-leaked-in-docker-hub-images-are-stolen-within-seconds/

**3. Siemens — Vague d'avis CISA sur produits industriels (11 advisories)**
La CISA publie simultanément 11 avis sur des produits Siemens : SIMATIC, WinCC, Mendix Studio Pro, RUGGEDCOM, Simcenter Femap, entre autres. Les systèmes SCADA/MES Siemens sont omniprésents en production pharmaceutique — revue de patch urgente à planifier avec les équipes OT/validation.
🔗 https://www.cisa.gov/news-events/ics-advisories/icsa-26-321-09

**4. Attaque via Optimizely — Supply chain web compromise sur CNN, BBC, Zoom**
Des scripts Optimizely (outil d'A/B testing tiers-parti) ont été détournés pour distribuer des card skimmers et des exploit kits iOS aux visiteurs de sites majeurs. Rappel critique du risque de la chaîne d'approvisionnement JavaScript pour tout portail patient ou site réglementaire pharma intégrant des scripts tiers.
🔗 https://thehackernews.com/2026/11/hijacked-optimizely-scripts-served-card.html

**5. Kit de phishing "TheMailer" — IA pilotant les attaques de spear-phishing**
Un nouveau kit de phishing autonome utilise l'IA pour personnaliser et orchestrer les campagnes sans intervention humaine, augmentant significativement le taux de succès. Les équipes R&D et affaires réglementaires, fréquemment ciblées pour leur propriété intellectuelle, sont particulièrement exposées.
🔗 https://www.darkreading.com/perimeter/themailer-phishing-kit-ai-drivers-seat

**6. Détournement de compte Hugging Face (modèle Kokoro) — Risque supply chain IA**
Des chercheurs ont démontré la compromission d'un compte Hugging Face hébergeant un modèle populaire, permettant la distribution de modèles malveillants. Toute équipe pharma utilisant des modèles open-source depuis Hugging Face (NLP réglementaire, analyse de données cliniques) doit vérifier l'intégrité des artefacts téléchargés.
🔗 https://www.bleepingcomputer.com/news/security/researchers-hijack-hugging-face-account-for-popular-kokoro-ai-model/
