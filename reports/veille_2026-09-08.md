## 🔐 Cyber

**1. Zero-day Magento "StyleSmuggler" — backdoor Linux déployé activement**
Un zero-day exploité sur Magento permet l'implantation d'un backdoor Linux sur les serveurs cibles. Risque direct pour les portails e-commerce et les environnements web pharma exposés (commandes en ligne, portails HCP).
🔗 https://www.bleepingcomputer.com/news/security/magento-stylesmuggler-zero-day-exploited-to-deploy-linux-backdoor/

**2. ConnectWise ScreenConnect — faille critique sans patch disponible**
ConnectWise signale une nouvelle vulnérabilité dans ScreenConnect sans correctif publié, exploitée activement via des clients ScreenConnect pirates diffusant une chaîne VBScript 4 étapes. Tout environnement utilisant ScreenConnect pour le support IT à distance est exposé immédiatement.
🔗 https://www.bleepingcomputer.com/news/security/connectwise-warns-of-new-screenconnect-flaw-without-patch/

**3. N-able N-central — 4e hotfix en 5 semaines pour RCE non authentifié (sévérité maximale)**
N-able publie un nouveau correctif d'urgence pour une faille RCE critique sur N-central, outil largement utilisé pour la gestion IT managée. Les MSP et équipes IT pharma opérant via N-central doivent appliquer le patch en priorité absolue.
🔗 https://www.bleepingcomputer.com/news/security/n-able-patches-max-severity-n-central-flaw-amid-ongoing-attacks/

**4. BigBear — service de phishing Microsoft 365 ayant contourné le MFA dans 258 organisations**
Un service PhaaS (Phishing-as-a-Service) a permis de bypasser le MFA sur M365 dans 258 organisations via interception de tokens. Les environnements pharma massivement sous M365 (Teams, SharePoint, Veeva-intégrations) doivent réévaluer leur stratégie MFA vers des méthodes résistantes au phishing (FIDO2).
🔗 https://www.bleepingcomputer.com/news/security/bigbear-microsoft-365-phishing-service-bypassed-mfa-at-258-organizations/

**5. Telerik UI — chaîne Padding-Oracle vers RCE non authentifié, exploit public disponible**
Une vulnérabilité de Telerik UI permet un RCE sans authentification via chaînage avec un bug padding-oracle ; un exploit public est désormais disponible. Telerik UI est fréquemment présent dans les applications internes pharma (portails qualité, ERP, LIMS) — patch ou mitigation réseau urgents.
🔗 https://thehackernews.com/2026/09/telerik-ui-padding-oracle-bug-chained.html

**6. Attaques de vishing ciblant les dirigeants — vol de données M365 et extorsion**
Des campagnes d'appels frauduleux imitant le support IT ciblent des cadres pour voler des credentials M365 et extorquer les entreprises. Le profil de menace est directement applicable aux environnements pharma avec des décideurs à forte valeur (accès données cliniques, IP).
