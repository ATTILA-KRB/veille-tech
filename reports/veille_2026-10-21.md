**1. Faille critique FortiSIEM — PoC public disponible (RCE non authentifié)**

*Impact : Toute infrastructure pharma utilisant FortiSIEM pour le monitoring SIEM doit appliquer le patch en urgence — le PoC public accélère drastiquement le risque d'exploitation.*

*Impact : Le MFA seul ne suffit plus comme rempart — les environnements OT/IT pharma sous Palo Alto doivent vérifier leur version de PAN-OS et appliquer les correctifs sans délai.*

**4. PHP : deux failles critiques RCE non patchées (CVSS 9.2) — alerte d'urgence**

*Impact : Les portails web pharma, applications cliniques et systèmes de reporting exposés en PHP doivent être isolés ou renforcés par WAF dans l'immédiat.*

**5. Compromission de 8 clés CA eMudhra — blocage d'urgence par Mozilla, Google, Apple**

**6. Agents IA autonomes utilisés pour compromettre des sites web à grande échelle (>1 200 cibles)**
