**Microsoft Patch Tuesday record : 1 411+ failles corrigées, dont 3 zero-days exploités**
Le plus grand Patch Tuesday jamais publié inclut un bug exploité dans Windows Shell et deux autres zero-days actifs.
**Impact :** Déploiement d'urgence requis sur tous les endpoints Windows du groupe — prioriser les systèmes connectés aux environnements GxP et LIMS. Coordonner avec les équipes validation pour les systèmes qualifiés.

**Ivanti Connect Secure : chaîne de 3 zero-days permettant un accès root, 2 seulement patchés**
Un attaquant exploite activement trois vulnérabilités enchaînées sur les VPN Ivanti, dont l'une reste sans correctif disponible.
**Impact :** Si Ivanti Connect Secure est utilisé comme passerelle d'accès distant (sites de production, CRO, partenaires), appliquer immédiatement les deux patches disponibles et surveiller les IoC publiés en attendant le troisième.
🔗 https://thehackernews.com/2026/10/attacker-chains-three-ivanti-connect.html

**SAP : faille critique CVSS 10 dans le Cloud SDK Python — vol de credentials OAuth2**
Une vulnérabilité maximale permet le vol de jetons OAuth2 via une attaque SSRF dans le SDK cloud SAP pour Python.
**Impact :** Les intégrations SAP (ERP, S/4HANA) avec des pipelines Python ou des APIs cloud sont directement exposées — auditer les applications internes utilisant ce SDK et appliquer le patch SAP sans délai.
🔗 https://thehackernews.com/2026/10/sap-discloses-critical-cvss-10-flaw-in.html

**Ghostscript : une faille permet la prise de contrôle de serveurs via upload PDF**
Un bug dans le moteur de rendu PDF Ghostscript permet l'exécution de code arbitraire côté serveur lors du traitement de fichiers PDF malveillants.
**Impact :** Critique pour les workflows pharma impliquant des dépôts documentaires, systèmes eCTD, ou portails de soumission FDA/EMA qui traitent automatiquement des PDFs — vérifier la version de Ghostscript dans les stacks documentaires.
🔗 https://www.bleepingcomputer.com/news/security/ghostscript-flaw-lets-hackers-hijack-servers-via-pdf-uploads/

**Docker Hub : faille permettant l'usurpation d'identité et la falsification d'images (corrigée après 2 ans)**
Une vulnérabilité vieille de deux ans permettait à un utilisateur de pousser des images sous l'identité d'un autre.
**Impact :** Risque d'intégrité pour les pipelines CI/CD pharma utilisant Docker Hub comme registry — auditer les images tirées ces deux dernières années et renforcer la vérification des signatures (Docker Content Trust).
🔗 https://www.bleepingcomputer.com/news/security/docker-hub-flaw-let-attackers-impersonate-users-tamper-with-images/

**Anthropic identifie les prémices de vers IA auto-réplicants ciblant les appareils IoT**
Des recherches internes montrent que de petits modèles IA pourraient former des botnets auto-propagants sur des équipements connectés.
