## 🔐 Cyber

**Java4Shell (CVE-2026-114938) — RCE pré-authentification sur Jira, Jenkins, Keycloak**
Faille critique dans l'écosystème Java permettant une exécution de code à distance sans authentification sur des outils d'infrastructure largement déployés en pharma. La CISA exige un patching immédiat ; toute instance Jira/Jenkins exposée est à considérer compromise jusqu'à preuve du contraire.
🔗 https://thehackernews.com/2026/11/java4shell-cve-2026-114938-enables-pre.html

**NGINX HTTP/2 — RCE non authentifié, faille vieille de 10 ans**
Une vulnérabilité dans le serveur web le plus répandu (225M de sites) permet une exécution de code arbitraire sans credentials. Les API pharma, portails de soumission réglementaire et reverse proxies NGINX sont directement exposés.
🔗 https://thehackernews.com/2026/11/10-year-old-nginx-http2-flaw-lets.html

**Apache Roller — RCE critique activement exploitée, sans authentification requise**
La vulnérabilité est déjà weaponisée ; Apache publie un avertissement officiel. Tout environnement utilisant Roller comme portail interne ou de publication documentaire doit être patché ou isolé en urgence.
🔗 https://www.bleepingcomputer.com/news/security/apache-warns-of-roller-rce-vulnerability-exploited-in-attacks/

**Package PyPI du framework agent Microsoft compromis pour vol de credentials**
Le package officiel Python du framework d'agents IA Microsoft a été détourné pour exfiltrer des identifiants. Les pipelines MLOps et environnements de développement IA en pharma utilisant ce package sont potentiellement compromis.
🔗 https://www.bleepingcomputer.com/news/security/microsofts-agent-framework-pypi-package-compromised-to-steal-credentials/

**F5 BIG-IP — 6 failles critiques pouvant provoquer des crashes de trafic et potentiellement du RCE**
Les équipements BIG-IP, fréquemment utilisés comme load balancers devant les systèmes GxP et ERP pharma, sont affectés dans des configurations spécifiques. Un crash de trafic sur ces équipements peut entraîner une indisponibilité de systèmes qualifiés.
🔗 https://thehackernews.com/2026/11/f5-warns-6-critical-big-ip-flaws-can.html

**CISA — 4 nouvelles vulnérabilités ajoutées au catalogue KEV (Known Exploited)**
La CISA a enrichi son catalogue de vulnérabilités activement exploitées ; Java4Shell et Apache Roller y figurent. Pour les environnements soumis à des exigences de conformité (NIST, NIS2), la fenêtre de remédiation est contractuellement contrainte.
🔗 https://www.cisa.gov/news-events/alerts/2026/11/18/cisa-adds-four-known-exploited-vulnerabilities-catalog

## 👁️ À surveiller

1. **Cluster de vulnérabilités RCE actives (Java4Shell + NGINX + Apache Roller + PHP)** : la concomitance de plusieurs failles critiques sans authentification sur des technologies fondamentales de l'infrastructure IT pharma constitue un risque systémique immédiat — un audit d'exposition est urgent avant fin de semaine.

2. **Gouvernance FDA post-Overton** : l'absence de leadership confirmé à la FDA dans un contexte politique instable pourrait allonger les délais de review et modifier les priorités de l'agence — à intégrer dans les plans de soumission 2026-2027.

3. **Fuite de prompts LLM et souveraineté des données** : la démonstration d'inversion de prompts, combinée à la compromission du package PyPI Microsoft, pose une question de sécurité concrète pour tout déploiement d'agents IA manipulant des données sensibles (IP, données cliniques, dossiers réglementaires) — une revue des politiques d'usage des API LLM s'impose.
