## CYBER

**1. JadePuffer : premier ransomware entièrement piloté par LLM**
Un groupe threat actor a déployé une chaîne d'attaque complète orchestrée par IA générative, de la reconnaissance à l'exfiltration. Impact : les outils de détection comportementale traditionnels sont contournés ; les SOC pharma doivent anticiper des attaques adaptatives ciblant les systèmes GxP et les données d'essais cliniques.
🔗 https://www.darkreading.com/cyberattacks-data-breaches/jadepuffer-first-complete-llm-driven-ransomware-attack

**2. Faille KVM Linux 16 ans / CVE-2026-53359 (Januscape) — escape guest-to-host**
Une vulnérabilité critique dans l'hyperviseur KVM permet à une VM invitée de s'échapper vers l'hôte sur architectures Intel et AMD x86. Impact : les infrastructures cloud privées et les environnements de calcul HPC/IA pharma (découverte de molécules, bioinformatique) hébergés sur KVM sont directement exposés ; patch à prioriser en urgence.
🔗 https://thehackernews.com/2026/07/16-year-old-linux-kvm-flaw-lets-guest.html

**3. NetScaler / CitrixBleed rechute — exploitation active**
Une nouvelle vulnérabilité NetScaler est activement exploitée, rappelant la vague CitrixBleed de 2023. Impact : les accès distants sécurisés (VPN, portails partenaires CRO/CMO) fréquents dans les groupes pharma sont en première ligne ; vérification immédiate des versions et segmentation réseau requises.
🔗 https://www.darkreading.com/vulnerabilities-threats/citrixbleed-ing-again-netscaler-vulnerability-under-attack

**4. Adobe ColdFusion — faille critique exploitée en conditions réelles**
La faille de sévérité maximale sur ColdFusion est désormais activement weaponisée. Impact : les portails intranet/extranet legacy et certains systèmes de gestion documentaire GxP encore sous ColdFusion doivent être patchés ou isolés immédiatement sous peine de compromission complète.
🔗 https://www.bleepingcomputer.com/news/security/max-severity-adobe-coldfusion-flaw-now-exploited-in-attacks/

**5. SkillCloak — techniques d'évasion pour agents IA malveillants**

Impact : avec la prolifération des agents IA dans les workflows pharma (rédaction réglementaire, analyse de données), la surface d'attaque via plugins/skills tiers devient critique ; auditer les registres d'agents déployés.
🔗 https://thehackernews.com/2026/07/new-skillcloak-technique-lets-malicious.html

**6. EtherRAT via faux support IT sur Microsoft Teams**
Des attaquants se font passer pour le support IT via Teams pour installer un RAT permettant la prise de contrôle à distance.
