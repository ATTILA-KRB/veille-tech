### 💻 IT / Tech

**1. Migration COBOL → Java par IA : les bugs migrent aussi**
Une étude arXiv démontre que les outils d'IA de migration de code COBOL vers Java reproduisent fidèlement les bugs fonctionnels du code source original.
*Impact : Pour tout projet de modernisation de systèmes legacy (LIMS, ERP, MES anciens), une validation fonctionnelle complète post-migration reste indispensable — ne pas présupposer que l'IA "corrige" les défauts existants.*
🔗 https://arxiv.org/abs/2607.28271

**2. Qwen 3.8-Max : nouveau modèle de référence pour le coding et la collaboration**
Alibaba publie Qwen 3.8-Max, qui s'impose comme nouvelle référence sur les benchmarks de génération et révision de code.
*Impact : Alternative open-weight sérieuse pour des cas d'usage internes (génération de scripts de validation, revue de code automatisée) sans dépendance à OpenAI — pertinent pour les équipes IT souhaitant des modèles déployables on-premise.*
🔗 https://qwen.ai/blog?id=qwen3.8

**3. RFC 9851 : TLS 1.2 en "feature freeze" officiel**
L'IETF officialise le gel des fonctionnalités de TLS 1.2, signalant sa dépréciation progressive au profit de TLS 1.3.
*Impact : Les systèmes pharma exposant des API ou des interfaces web (portails eTMF, CTMS, systèmes de soumission réglementaire) doivent planifier la migration TLS 1.3 — risque de non-conformité à moyen terme vis-à-vis des exigences NIST/FDA cybersecurity guidance.*
🔗 https://www.rfc-editor.org/rfc/rfc9851.html

**4. OpenAI finance via son Super PAC un site d'information généré par IA**
OpenAI utiliserait son bras politique pour financer un média entièrement généré par IA visant à influencer le débat réglementaire sur l'IA.
*Impact : Signal d'alerte sur l'intégrité des sources d'information en veille réglementaire IA ; renforce la nécessité de croiser les sources avant toute prise de décision stratégique basée sur des contenus IA-générés.*
🔗 https://www.modelrepublic.org/articles/the-reporters-at-this-news-site-are-ai-bots.-openai%E2%80%99s-super-pac-appears-to-be-using-it-to-advance-its-political-agenda
