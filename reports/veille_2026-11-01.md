## 🔐 Cyber

**Northflank : fuite de clés API d'IA clients**
Des clés API d'IA hébergées sur la plateforme Northflank ont été compromises suite à une brèche. Impact : risque direct si votre organisation utilise des services cloud mutualisés pour exposer des API d'IA en environnement de développement ou de recherche — audit immédiat des clés API tierces recommandé.
🔗 https://www.bleepingcomputer.com/news/security/northflank-security-breach-leads-to-abuse-of-customers-ai-api-keys/

**Chainalysis : intrusion via "techniques agentiques offensives"**
Un acteur malveillant a utilisé des agents IA autonomes pour s'introduire dans les systèmes de Chainalysis et exfiltrer des données d'identité clients. Impact : signal fort que les agents IA constituent désormais un vecteur d'attaque mature — à intégrer dans les modèles de menace et les revues de sécurité des pipelines IA pharma.
🔗 https://www.bleepingcomputer.com/news/security/chainalysis-discloses-data-breach-from-offensive-agentic-techniques/

**Ivanti Connect Secure : chaîne de 3 failles vers accès root non authentifié**
Des attaquants enchaînent trois vulnérabilités dans Ivanti Connect Secure pour obtenir un accès root sans authentification. Impact : critique pour tout site pharma utilisant Ivanti comme passerelle VPN/accès distant — patch immédiat requis, vérification des logs d'accès.
🔗 https://thehackernews.com/2026/10/attackers-chain-three-ivanti-connect.html

**CVE-2026-98432 : TCP Use-After-Free Linux, CVSS 9.8**
Une vulnérabilité critique dans la pile TCP/IPv4 Linux permet une exécution de code arbitraire à distance. Impact : concerne tout serveur Linux non patché (infrastructures HPC, serveurs de données cliniques, systèmes de manufacturing connectés) — mise à jour noyau à prioriser.
🔗 https://atlasum.net/blog/cve-2026-98432-linux-ipv4-tcp-uaf

**Android "SMS of Death" : crash à distance des téléphones non patchés**
Un exploit permet de planter à distance tout smartphone Android non mis à jour via un simple SMS malformé. Impact : concerne les flottes mobiles terrain (MR, équipes cliniques) utilisant des appareils Android non patchés — inventaire et politique de mise à jour MDM à vérifier.
🔗 https://www.bleepingcomputer.com/news/security/new-android-sms-of-death-exploit-can-remotely-crash-unpatched-phones/
