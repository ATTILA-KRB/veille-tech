## 🔴 Cyber

**PHP2Shell / HTTP2Shell — Exploitation active confirmée par la CISA**
Des failles critiques d'exécution de code à distance dans PHP (liées à la bibliothèque Brotli) sont activement exploitées in the wild, avec des patches d'urgence émis par Microsoft (.NET) et PHP en moins de 5 jours. Impact concret : tout serveur web ou middleware pharma exposant PHP ou .NET doit être patché en urgence — les systèmes de gestion de données cliniques, portails CTMS ou API de soumission FDA/EMA sont en première ligne.
🔗 https://thehackernews.com/2026/10/cisa-confirms-active-exploitation-of.html | https://www.bleepingcomputer.com/news/security/critical-http2shell-brotli-vulnerability-triggers-emergency-patches/

**LiteLLM — Attaque supply chain via une master key exposée**
Une clé maître LiteLLM compromise a permis une attaque de chaîne d'approvisionnement ciblant des infrastructures LLM d'entreprise. Impact concret : les équipes déployant des passerelles LLM internes (ex. pour accès aux modèles en environnement GxP) doivent auditer immédiatement la gestion de leurs secrets et revoir leurs politiques de rotation de clés API.
🔗 https://www.theregister.com/security/2026/10/26/litellm-supply-chain-attack-started-with-an-exposed-master-key/5305544

**Gheist — Vol de secrets cloud via tokens GitHub volés**
Le groupe Gheist exploite des tokens GitHub compromis pour extraire des secrets de dépôts privés via les logs GitHub Actions. Impact concret : les pipelines CI/CD pharma (validation de packages, déploiement d'outils réglementaires) doivent faire l'objet d'un audit des permissions GITHUB_TOKEN et des secrets stockés en clair dans les logs.
🔗 https://www.darkreading.com/cyberattacks-data-breaches/gheist-stolen-github-tokens-cloud-secrets

**ARTEX AI — Ex-pentester utilise l'IA pour voler 8,2 millions de records**
Un ancien professionnel de la sécurité a utilisé un outil d'IA offensif (ARTEX) pour exfiltrer des données massives, illustrant la menace insider augmentée par l'IA. Impact concret : les accès privilégiés aux systèmes de données patients ou de R&D doivent intégrer une surveillance comportementale renforcée, notamment pour les prestataires externes disposant de droits élargis.
🔗 https://www.bleepingcomputer.com/news/security/former-pentester-used-artex-ai-to-steal-82-million-data-records/

**Attaque in-the-wild via Markdown sur agents IA**
Des attaquants exploitent la confiance des agents IA dans le rendu Markdown pour injecter des actions malveillantes (prompt injection). Impact concret : les agents IA déployés dans des workflows pharma (résumés de littérature, rédaction de CSR, analyse de données cliniques) doivent être testés contre les injections de prompt et isolés des surfaces d'écriture non maîtrisées.
🔗 https://www.darkreading.com/application-security/in-the-wild-attack-ai-agents-trust-markdown

**Microsoft Teams — Scams IT support déployant ransomware**
Des attaquants se font passer pour le support IT via Teams pour déployer malwares et ransomwares sur les postes cibles. Impact concret : dans un contexte pharma où Teams est central aux collaborations CRO/CMO, une campagne de sensibilisation ciblée et le durcissement des paramètres d'accès externe Teams sont à prioriser.
🔗 https://thehackernews.com/2026/10/attackers-use-microsoft-teams-it-support-scams-to-deploy-malware-and-ransomware/

## 💻 IT / Tech

**KV Cache exposure sur GLM-5.3 (Cloudflare Workers AI)**
Une fuite de cache inter-requêtes a exposé des réponses d'autres utilisateurs sur un modèle LLM hébergé par Cloudflare, révélant un risque d'isolation des données en environnement multi-tenant. Impact concret : toute utilisation d'API LLM cloud pour des données sensibles (dossiers patients, données d'essais) doit être conditionnée à des garanties d'isolation strictes — ce cas constitue un argument fort pour des déploiements on-premise ou des SLA contractuels explicites.
🔗 https://blog.cloudflare.com/kv-cache-exposure-remediation/

## 🔭 À surveiller

1. **Vulnérabilités PHP2Shell/Brotli** — L'exploitation active confirmée par la CISA et la rapidité des correctifs (deux patches en 5 jours) suggèrent une surface d'attaque encore partiellement non patchée. Surveiller les bulletins CISA et évaluer l'exposition des stacks web internes d'ici 72h.

2. **Sécurité des agents IA en environnement pharma** — La convergence de trois signaux cette semaine (injection via Markdown, vol massif par IA offensif ARTEX, identité des agents comme preuve d'incident) dessine un risque systémique émergent pour les déploiements d'agents IA en contexte réglementé — un cadre de gouvernance spécifique devient urgent.

3. **Souveraineté des données IA** — Les incidents Qwen (exfiltration vers la Chine) et KV cache (Cloudflare) illustrent que les garanties contractuelles des fournisseurs LLM cloud ne suffisent pas. Une politique de classification des données compatible avec les exigences GxP avant tout déploiement LLM s'impose comme chantier prioritaire.
